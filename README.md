# اپ اندروید قیمت لحظه‌ای انس جهانی طلا (پاپ‌آپ روی صفحه)

این پروژه یک اپلیکیشن اندروید کامل (Kotlin) است که یک حباب شناور (Floating Overlay)
روی صفحهٔ گوشی نمایش می‌دهد و قیمت لحظه‌ای انس جهانی طلا (XAU/USD) را نشان می‌دهد.
حباب قابل جابه‌جایی است و حتی وقتی از اپ‌های دیگر استفاده می‌کنید هم روی صفحه باقی می‌ماند.

## ساختار پروژه
یک پروژهٔ استاندارد Android Studio (Gradle) است:
```
GoldPriceOverlay/
├── app/
│   ├── build.gradle
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/example/goldoverlay/
│       │   ├── MainActivity.kt      -> صفحهٔ اصلی، گرفتن مجوز و کلید API
│       │   ├── OverlayService.kt    -> سرویس نمایش حباب شناور روی صفحه
│       │   ├── GoldPriceApi.kt      -> اتصال به API قیمت طلا
│       │   └── PrefsManager.kt      -> ذخیرهٔ کلید API
│       └── res/...
├── build.gradle
└── settings.gradle
```

## نیازی به API Key نیست! ✅
این اپ از سرویس رایگان و بدون محدودیت **Gold-API.com** استفاده می‌کند
(https://gold-api.com) که نیازی به ثبت‌نام، کلید API یا محدودیت تعداد
درخواست در ماه ندارد. فقط اپ را نصب کن و مستقیماً کار می‌کند.

> اگر بخواهید از سرویس دیگری استفاده کنید، فقط کافیست در فایل
> `GoldPriceApi.kt` آدرس URL و نحوهٔ خواندن JSON پاسخ را با مستندات
> همان سرویس تطبیق دهید.

## ساخت APK آنلاین بدون نصب هیچ برنامه‌ای (با GitHub) — روش پیشنهادی

این پروژه از قبل یک فایل خودکارسازی (`.github/workflows/build-apk.yml`) داره که
باعث میشه GitHub خودش پروژه رو build کنه و فایل APK رو تحویل بده. کافیه این
مراحل رو دنبال کنی:

1. **ساخت حساب رایگان GitHub** (اگر نداری): برو به https://github.com/join و
   ثبت‌نام کن.

2. **ساخت یک مخزن (Repository) جدید**: به آدرس https://github.com/new برو،
   یک اسم دلخواه بذار (مثلاً `GoldPriceOverlay`)، و روی «Create repository» بزن.
   لازم نیست تیک "Add a README file" رو بزنی.

3. **آپلود فایل‌های پروژه**: در صفحهٔ مخزن تازه‌ساخته‌شده، روی لینک
   «uploading an existing file» کلیک کن. سپس پوشهٔ `GoldPriceOverlay` رو که از
   داخل zip استخراج کردی (تمام محتویاتش، نه خود فایل zip) بکش و داخل صفحهٔ
   مرورگر رها کن (Drag & Drop). صبر کن آپلود کامل بشه، بعد پایین صفحه روی
   «Commit changes» بزن.

4. **رفتن به تب Actions**: بالای صفحهٔ مخزن، روی تب **Actions** بزن. اگر پیامی
   دربارهٔ فعال‌سازی workflow دیدی، روی «I understand my workflows, go ahead
   and enable them» بزن. یک اجرای build به‌صورت خودکار شروع میشه (چون همین
   آپلود، یک push به شاخهٔ اصلیه). حدود ۳ تا ۵ دقیقه صبر کن تا علامت آن به
   ✅ سبز تبدیل بشه.

5. **دانلود APK**: روی همون اجرای build (که اسمش چیزی شبیه "Build APK" هست)
   کلیک کن. پایین صفحه، بخش **Artifacts** رو پیدا کن و روی
   `GoldPriceOverlay-debug-apk` بزن تا یک فایل zip کوچک دانلود بشه.

6. **نصب روی گوشی**: فایل zip دانلودشده رو باز کن؛ داخلش `app-debug.apk` هست.
   این فایل رو به گوشی اندرویدی منتقل کن (از طریق تلگرام، ایمیل، یا کابل) و
   روش ضربه بزن تا نصب بشه. ممکنه اندروید بخواد اجازهٔ «نصب از منابع ناشناس»
   (Install unknown apps) رو برای همون اپی که فایل رو باهاش باز کردی (مثلاً
   File Manager یا Telegram) فعال کنی — این یک هشدار امنیتی استاندارد
   اندرویده و چون خودت فایل رو ساختی، مشکلی نداره.

> نکته: هر بار که فایلی از پروژه رو تغییر بدی و دوباره در GitHub «Commit» کنی،
> این فرایند به‌صورت خودکار دوباره اجرا میشه و یک APK جدید می‌سازه.

## مرحله ۲ (روش جایگزین): باز کردن و اجرای پروژه در Android Studio
1. آخرین نسخهٔ Android Studio را نصب کنید.
2. گزینهٔ **Open** را زده و پوشهٔ `GoldPriceOverlay` را انتخاب کنید.
3. صبر کنید Gradle Sync کامل شود (نیاز به اینترنت دارد تا کتابخانه‌ها دانلود شوند).
4. گوشی خود را با USB Debugging وصل کنید یا از یک شبیه‌ساز (Emulator) استفاده کنید.
5. دکمهٔ Run (▶) را بزنید.

## مرحله ۳: استفاده از اپ روی گوشی
1. اپ را باز کنید.
2. API Key را وارد و ذخیره کنید.
3. روی «فعال‌سازی مجوز نمایش روی اپ‌ها» بزنید و در تنظیمات اندروید اجازه را فعال کنید
   (این یک مجوز امنیتی است که خود اندروید برای هر اپی که می‌خواهد روی صفحه پاپ‌آپ نشان دهد الزامی کرده).
4. روی «شروع نمایش پاپ‌آپ» بزنید.
5. حباب طلایی رنگ روی صفحه ظاهر می‌شود و هر ۱۵ ثانیه یک‌بار قیمت را به‌روزرسانی می‌کند.
   می‌توانید آن را با انگشت جابه‌جا کنید یا با ضربه روی علامت ✕ ببندید.
6. برای توقف کامل، در اپ روی «توقف پاپ‌آپ» بزنید.

## تغییر فاصلهٔ زمانی به‌روزرسانی
در فایل `OverlayService.kt`، مقدار زیر را تغییر دهید:
```kotlin
private val updateIntervalMs = 15_000L // به میلی‌ثانیه
```

## نکات
- پلن رایگان اکثر APIهای قیمت طلا محدودیت تعداد درخواست ماهانه دارد؛ اگر فاصلهٔ
  به‌روزرسانی را خیلی کم کنید (مثلاً هر ۱ ثانیه) ممکن است سهمیهٔ رایگان زود تمام شود.
- برای انتشار روی گوشی‌های دیگر باید اپ را Build > Generate Signed Bundle/APK کنید.
